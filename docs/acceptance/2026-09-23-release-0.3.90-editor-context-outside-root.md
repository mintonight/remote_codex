## 故障现场

`igh_test` Remote SSH 窗口的规范主根为 `/home/humanoid/Test/igh_test`，同一
`ssh-remote+x2_n1` authority 的活动编辑器却位于另一项目。`0.3.89` 对该文件执行
`workspaceRelativePath` 返回 `PATH_OUTSIDE_ROOT`；Shim 的自动上下文请求因此拒绝
`turn/start`，官方日志在 2026-09-24 04:18:51 UTC 对任务
`01a0d1a3-28b6-71b2-a593-4eb9edd625ff` 记录 `-32003`。Bridge 审计同时记录
`editor_context.inject=failed`、原因 `Workspace resource is outside its root`。
未读取或记录活动编辑器正文；不改写工作区 URI，也不另起 SSH 认证。
