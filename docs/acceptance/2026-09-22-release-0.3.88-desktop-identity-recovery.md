## 修复边界

只在 Linux 活跃本地服务的严格发现未命中时，执行附加只读验证：

1. 使用现有描述符结构解析器，限定 ready、本地共享服务和真实 native 配置域。
2. 校验服务/native 进程可执行文件 inode，确认环回 TCP 监听 socket 归该服务 PID。
3. 使用既有凭据执行 initialize 和 bridge/service/status，核对服务与 native PID。
4. 重新核验两进程身份及监听 socket，验证期间身份变化或任何操作失败均拒绝恢复。

全局 processIdentitiesMatch 时间容差未变；进程终止和孤立后台接管规则未放宽。
没有运行时版本门禁，没有备用 native 启动，没有自动 SSH 认证或主机密钥变更。
