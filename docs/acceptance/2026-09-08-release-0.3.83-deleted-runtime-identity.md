## 修正与安全边界

Linux 检查改用 readlink(`/proc/pid/exe`) 和 stat(`/proc/pid/exe`)；即使目录项删除，
仍可获得运行中映像的设备/inode。新描述符在 PID、启动时间之外保存文件身份，
支持路径迁移而不放宽到仅匹配 PID 或进程名称。

旧 v3 记录没有文件身份时，只有在启动时间吻合，且原 argv、app-server 参数、受管
token 路径、监听 socket 实际所属和私有鉴权协议响应均通过后，才建立新的完整身份。
记录不可信时明确拒绝选择空竞争者；不会为了恢复 UI 而终止用户进程或删除 writer lock。
清理器也保留同一进程生命周期中发生路径变化的旧记录，避免接管前丢失凭据。

Linux 对删除后 exe 链接的语义依据：
[proc_pid_exe(5)](https://man7.org/linux/man-pages/man5/proc_pid_exe.5.html)。
