## 行为

Webview 先向 Workbench 发送带 nonce 的 probe。Workbench 确认唯一可见 Codex pane
并调用已注册的 Bridge dropReady 命令；返回 true 才应答。Webview 只接受 top 窗口
对当前 nonce 的及时应答。确认最多有效 1.5 秒，拖动期间按需刷新，不开启后台轮询。
Workbench 在初始 pane 隐藏时也记住探测来源，显示后能在拖动时重新探测。

没有应答、nonce/source 不符、应答过迟、Bridge 命令不存在或确认过期时，不调用
preventDefault/stopPropagation 抢走原生拖放。Workbench 的文档捕获与 Webview 转发
都检查就绪状态。握手是接收能力/活性检测，不应被描述为新的用户授权机制。

受管文件与当前生成器输出不同时，inspect 返回 update-available；enable 仍从经过
SHA-256 验证的原件重新生成补丁，不覆盖未知改动。明确拒绝仍缓存，失败安装不再
提前记成成功/拒绝。成功安装后仅提示手动重载，不主动中断用户窗口。
