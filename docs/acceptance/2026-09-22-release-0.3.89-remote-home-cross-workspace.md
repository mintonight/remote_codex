## 遗留风险与结论

- 仅含 `CodeFiles` 路径而没有同 authority 远端 URI 的跨工作区拖放无法证明来源，故失败关闭；真实 VS Code 窗口需确认实际 DataTransfer 是否提供 URI。
- 另一个 SSH 主机或用户不在本目标范围内；不同 authority 在远端 stat 前拒绝，避免触发第二次认证。
- `remote_exec` 不是远端文件系统沙箱；home 作用域只限制结构化操作与命令启动目录，不限制命令参数访问其他绝对路径。
- 此记录覆盖的 Linux 行为足以保存并推送源码候选，但缺失的双向审计、负测、
  Windows 原生包与运行结果仍阻止完整发布支持声明。
- 最终结论：待补测，不得写入当前支持矩阵。
