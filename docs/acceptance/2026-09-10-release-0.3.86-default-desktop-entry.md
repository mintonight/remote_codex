# 0.3.86 默认桌面入口与受控重启

本地日期：2026-09-10；日志使用 UTC 2026-09-11。基线为尚待正式验收的 0.3.85。
本次触发桌面入口、Controller 包和生命周期回归；Executor 0.2.21 实现/协议未变。

## 故障与修复

用户重启后桌面主进程变为 913183，父进程为 gnome-shell，native 子进程为 913683。
新进程仍未携带 CODEX_CLI_PATH 或 CODEX_BRIDGE_DESKTOP_CLIENT。与此同时，VS Code
审计持续出现成功的 client.callback_route。说明桌面确实重启了，但共享启动环境未
生效，不能再次归因于用户没有重启或笼统归因于回调实现。

0.3.85 只增加独立入口，原图标仍可绕开共享启动器。现在使用 desktop-file-edit
生成同名用户级 chatgpt.desktop：保留 Name/Icon/MimeType 等属性，替换 Exec/TryExec，
关闭绕过 Exec 的 D-Bus 激活。系统 desktop entry 与官方应用资源不修改。已有用户
自定义入口按内容哈希保存原件，卸载逐字节恢复；原来没有用户覆盖则卸载时删除覆盖。
用户后续修改的文件不会被强制覆盖/删除；安装事务与原件校验支持中断恢复及再安装。

用户已明确授权：修好后退出旧桌面端并从共享入口重启。重启助手校验 PID、启动 ticks
和 executable，仅 SIGTERM 桌面主进程，不升级 SIGKILL，不对 VS Code、训练、native
共享后台或进程组发送终止信号。新桌面必须带共享标记、产生正确 Shim 子进程，并有
本轮新 desktop shared_attached 审计，才记录 shared-client-ready。
