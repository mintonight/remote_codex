## 修正

- 在查找旧实例或 spawn 之前，读取当前 Extension Host 的结构化工作区记录。
- 文件未就绪时最多等待 5 秒，期间不新建 app-server；超时明确失败，不猜测 home 根。
- 显式 null 表示没有单一工作区，与记录缺失区分；不修改 VS Code 工作区 URI。
- 对同根多个遗留实例只读检查 loaded 集合：唯一非空实例优先，全部为空时可选择最新
  空实例；多个非空或状态未知时拒绝自动选择。保留进程身份校验与互斥接管。
- 不强杀当前原线程的持有者，不清除官方 writer lock 或删除历史。
